spike-html-design

This page renders every token, element and tool class in the baseline with the full entry, full.css, alone. It follows the system color scheme; set data-scheme or data-palette on any element to force a scheme or apply a color profile to its subtree.

Each token is shown with a sample that uses it. Fluid values grow from a 22.5rem display to an 80rem one; resize the window to watch them change.

Elements

The elements layer styles every rendered element without classes, and each keeps its native layout and behavior. Three hooks recolor a subtree: --interaction-color for links, focus, selection and hover borders, --code-color for inline code, and --kbd-color for keys.
