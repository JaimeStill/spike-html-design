Specimen · five color profiles, light and dark

The baseline's tokens, every element its elements layer styles, and its tools, rendered by baseline.css alone. It follows the system scheme; a data-scheme of light or dark on any element forces one for its subtree, and a data-palette applies a color profile to its subtree.

Elements

Every rendered element as the elements layer styles it, with no classes: paint, type, borders, radius, margins and paddings only, so each keeps its native layout and behavior. Each cell's label names the elements it shows. A consumer re-colors them through three hooks, set on any element for its subtree: --interaction-color for links, focus, the caret, accents, selection and hover borders, by default --blue; --code-color for inline code; and --kbd-color for keys.

    Contrast

    Contrast is graded where legibility matters: text over a color. Each color profile records it in each scheme, in a matrix that grades every text token and hue, its rows, over every surface and border, its columns, by the WCAG 2 ratio from relative luminance. Each matrix sits in a container that names its profile and forces its scheme. Each mark is judged on the unrounded ratio, so a 4.50 can still be AA-L and a 3.00 can still fail. Surfaces and borders get no ratio of their own. Failures are recorded here, not corrected.

    AA
    4.5 or more: meets AA for body text.
    AA-L
    3 or more, under 4.5: meets AA for large text only.
    fail
    Under 3: meets neither.
